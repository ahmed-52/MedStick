## Introduction

AI Chat - AlignUI AI Assistant & Chat Template for Next.js. A modern, responsive AI chat interface with project management, settings, and authentication features.

## Getting Started

First, install dependencies:

```bash
pnpm i
```

Run the development server

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Pages

### Dashboard

- [New Chat](http://localhost:3000) - Main chat interface
- [Chat Conversation](http://localhost:3000/chat/1) - Active chat conversation
- [Projects](http://localhost:3000/projects) - Project management
- [Project Detail](http://localhost:3000/projects/1) - Individual project view
